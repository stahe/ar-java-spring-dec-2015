يحتوي هذا المستودع على الموقع الإلكتروني الثابت للدورة التدريبية والتمارين (TD) بعنوان "مقدمة إلى لغة جافا ومنظومة سبرينغ".

## 📚 معلومات عن هذا المستند

هذه المواد التعليمية مخصصة للطلاب المبتدئين في المجال الجامعي. وهي تجمع بين المفاهيم النظرية للدورة التدريبية والتمارين العملية.

### أهداف التعلم

الهدف الرئيسي هو تعليم لغة Java من منظور **مهني**. ولهذا السبب، تعتمد الدورة التدريبية بشكل كبير على إطار العمل **[Spring](http://spring.io/)**، وهي تقنية تُستخدم في تطوير **JEE** (Java Enterprise Edition).

وبطبيعة الحال، تعمل هذه الوحدة كمدخل تمهيدي قبل الالتحاق بدورة JEE متخصصة.
